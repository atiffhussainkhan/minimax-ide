# 🐍🪜 Snake & Ladder — 3D Cartoon Edition

A complete snake-and-ladder board game that runs in any modern browser. Hot-seat
for 1–4 players, over a competition of **1, 3, 5, 7 or 9 games**. Built with
only free assets — **no accounts, no API keys, no payment, no ads.**

## Overview

- **1–4 players**, hot-seat on one device.
- **Competitions of 1, 3, 5, 7 or 9 games.** A competition always plays every
  game you selected, then shows one final champion screen, then returns you to
  the setup screen so you can start another one. A single game win never ends
  the competition early.
- **Classic zig-zag board** — square 1 bottom-left, 11 directly above 10,
  21 above 20, 100 top-left.
- **Slim, readable snakes.** Each snake has exactly one head (a face, on the
  start square) and one tail, with a ring on the square it slides to. Drawn as
  pure vector SVG, so they stay crisp at any size.
- **Full keyboard play** — <kbd>R</kbd> or <kbd>Space</kbd> rolls,
  <kbd>Enter</kbd> advances between games.
- Respects `prefers-reduced-motion` and `prefers-color-scheme`, and shows a
  visible focus ring for keyboard players.

## Run it

Open `index.html` in any modern browser:

```bash
open game/index.html           # macOS
xdg-open game/index.html       # Linux
start game/index.html          # Windows
```

…or serve it locally for cleaner dev tools:

```bash
cd game && python3 -m http.server 8000
# then visit http://localhost:8000
```

## Verify it

The whole QA suite runs **headless** in JavaScriptCore against the real
`game.js` — no browser, no display, no network, no dependencies:

```bash
cd game
bash tools/run_all.sh          # 1000 stress tournaments (the default)
bash tools/run_all.sh 50       # quick pass
```

Five gates, all must pass:

| Gate | What it proves |
|---|---|
| `tools/enduser_test.js` | 47 checks driving the real buttons and keyboard through a full competition, an abandon, and a restart |
| `tools/check_board_map.py` | Every ladder lands ≥2 squares clear of every snake bite |
| `tools/stress_test.js` | 1000 randomised tournaments (1–4 players × 1/3/5/7/9 games, unique RNG seed each) plus the autoplay hook |
| `tools/audit_unused.py` | No unused assets, functions, constants or CSS classes |
| `tools/render_board.js` | Renders the real board to PNG for a visual check |

Individual checks are runnable on their own, e.g.:

```bash
python3 tools/check_board_map.py     # board invariants
python3 tools/audit_unused.py        # dead-code sweep
```

## Board map

Snakes (head → tail):

| 99 → 54 | 95 → 72 | 67 → 55 | 52 → 42 | 25 → 2 |
|---|---|---|---|---|

Ladders (foot → top):

| 6 → 30 | 11 → 33 | 20 → 59 | 27 → 74 | 36 → 57 |
|---|---|---|---|---|
| **51 → 69** | **63 → 81** | **71 → 91** | **80 → 93** | |

### The clearance rule

> Every `|ladder landing − snake bite|` must be **≥ 2**.

The move logic resolves the ladder first and the snake second, so a ladder that
lands on — or next to — a snake either bites you on arrival or is a trap. Two
squares of clearance means a player who climbs always gets to stand on solid
ground. `tools/check_board_map.py` enforces this automatically and is part of
the suite, so the map cannot silently drift back.

## Rules

- Players take turns rolling a 6-sided die (press <kbd>R</kbd>, <kbd>Space</kbd>,
  or click **🎲 Roll Dice**).
- Move forward that many squares, zig-zag from 1 bottom-left.
- 🪜 Land on a ladder foot to climb it; 🐍 land on a snake head to slide down.
- **Roll exactly 100 to win.** Roll higher and you bounce and stay put.
- A competition ends after the last game, shows the overall champion, then
  returns to the setup screen. **⏹ End Tournament** abandons a run on purpose.

## What's in the box

| Path | Purpose |
|---|---|
| `index.html` | Markup, meta tags, asset references |
| `style.css` | All styling — board grid, dice, sidebar, modals, a11y |
| `game.js` | All game logic: turns, dice, snakes/ladders, tournaments, vector snake renderer |
| `manifest.webmanifest` | PWA manifest |
| `assets/board.jpg` | 3D cartoon jungle board art (652×675) |
| `assets/pawn_{red,blue,green,yellow}_transparent.png` | 3D cartoon pawns, one per player |
| `assets/ladder_transparent.png` | Wooden ladder prop at each ladder foot |
| `assets/dice.png` | 3D cartoon die |
| `assets/favicon.svg`, `assets/apple-touch-icon.png` | Icons (generated by `tools/make_icons.py`) |
| `tools/` | The headless QA suite described above |

The **snakes are not images** — `draw3DSnake()` builds them as SVG: a tapered
ribbon body with a round head, two eyes, a forked tongue, and an end ring. That
replaced an earlier raster sprite that was tapered at both ends and read as
"two tails" with no head.
